# 12. Glossary

The domain vocabulary of Umbra lives in a single place: the root [`GLOSSARY.md`](../../GLOSSARY.md). This section deliberately does not duplicate it.

Rendering terminology follows _Physically Based Rendering: From Theory to Implementation_, 4th edition; `GLOSSARY.md` lists only the terms specific to Umbra, or the pbrt-v4 terms whose meaning Umbra narrows or changes.
