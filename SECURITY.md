# Security Policy

## Supported versions

Umbra is pre-1.0. Only the latest release and the `develop` branch receive
security fixes.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Report them privately through GitHub Private Vulnerability Reporting:

1. Go to the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Describe the issue, the affected version or commit, and the steps to
   reproduce it inside the devcontainer.

Direct link: <https://github.com/sergioffpc/umbra/security/advisories/new>

You should receive an acknowledgement within 7 days. The maintainers will
work with you on a fix and a coordinated disclosure, and credit you in the
advisory unless you prefer to remain anonymous.

## Code of conduct reports

The same private channel is used to report violations of the
[Code of Conduct](CODE_OF_CONDUCT.md). Reports are reviewed only by the
maintainers and kept confidential.
