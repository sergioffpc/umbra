# Security Policy

## Supported versions

Umbra is in early development. Only the latest commit on `main` receives
security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/sergioffpc/umbra/security/advisories/new).
Do not open a public issue.

Include a description of the issue, steps to reproduce it, and its potential
impact. You can expect an acknowledgement within 7 days. Once a fix is
available, the advisory will be published with credit to the reporter unless
you ask to remain anonymous.
